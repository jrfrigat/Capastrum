# Security Policy

## Supported versions

Capastrum is pre-1.0; only the latest published version of each package receives security fixes.

| Version | Supported |
| :-- | :-- |
| latest | yes |
| older | no |

## Reporting a vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Use GitHub's private reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the issue, the affected package and version, and the steps to reproduce it.

Reports are acknowledged as soon as possible and kept confidential until a fix is available. Please allow reasonable time to address the issue before any public disclosure.
